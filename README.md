# GS Viewer

3DGS 实验渲染结果对比工具。将多个实验的渲染图片并排展示在同一个页面中，方便横向对比效果。

## 功能

- **目录加载** — 输入实验根目录，自动列出所有子目录（实验）
- **多选对比** — 勾选多个实验，将同一视角的渲染图并排显示
- **自适应网格** — 根据选中数量自动调整布局：2个左右并排、4个田字格、6个2×3……
- **test/train 切换** — 一键切换查看测试集或训练集的渲染结果
- **GT 对照** — 可叠加显示 Ground Truth 作为参考
- **键盘导航** — ← → 切换图片，⏪ ⏩ 跳10张
- **搜索过滤** — 在目录列表中按名称搜索，纯前端过滤，不耗流量

## 启动

```bash
cd submodules/gs_viewer
python server.py --path /mnt/data2/experiments/3dgs/output_sem --port 8765
```

然后浏览器打开 `http://localhost:8765`。

参数：
- `--path` — 实验根目录的默认路径（可选，也可在页面中手动输入）
- `--port` — 服务端口（默认 8765）

## 目录结构要求

每个实验子目录需包含 `test/` 或 `train/` 文件夹，内部有任意迭代文件夹（如 `ours_1500/`），其下包含 `renders/`（必需）和 `gt/`（可选）：

```
实验根目录/
├── experiment_01/
│   └── test/
│       └── ours_1500/
│           ├── renders/
│           │   ├── 00000.png
│           │   └── ...
│           └── gt/          # 可选，用于GT对照
│               └── 00000.png
├── experiment_02/
│   └── test/
│       └── ours_1500/
│           └── renders/
│               └── ...
└── ...
```
